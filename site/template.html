How it works

Read the design. Rebuild it.

  1. Read the structure

    The input has no labels. Size, position and grouping tell it which piece is the headline, logo, product and button.

  2. Try real layouts

    A column, a side-by-side split, three columns or a single row, each in the original reading order.

  3. Measure and score

    Text is measured with the official renderer's fonts. Each layout is scored on readability, hierarchy, collisions and space.

  4. Pick and explain

    The best layout wins, and every decision is recorded so you can see why.

Limits. Very long copy stays small on tiny banners, because copy is never rewritten. On small canvases, unreadable low-priority pieces may be hidden, and a switch turns that off. Numbers are our own checks, not Adobe's scorer.

Run it

Three commands

# Python 3.10+, inside the starter repo
pip install -r requirements.txt
python -m engine.main      # resize every task in input/
python -m studio.server    # demo UI on http://127.0.0.1:8765
